## Spacing, shapes and controls

| Token                                  | Use                                                                                                                           |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `--space-1` to `--space-12`            | margins, gutters, inner spacing (4 to 48 px); `--space-2` (8 px) between related elements, `--space-4` (16 px) between blocks |
| `--radius-md`                          | corners of buttons, fields and cards; `--radius-lg` for modals and sheets; `--radius-pill` for filters and tabs               |
| `--control-md`                         | default control height (44 px, minimum touch target); `--control-lg` and `--control-xl` for highlighted actions               |
| `--focus-ring`                         | focus ring, set by `base.css` on `:focus-visible`                                                                             |
| `--z-header` to `--z-toast`            | stacking: header, overlay, modal, toast                                                                                       |
| `--duration-fast`, `--duration-normal` | transitions, neutralised when the user reduces motion                                                                         |

Breakpoints (min-width, mobile first): 480, 768, 1024 and 1280 px.
