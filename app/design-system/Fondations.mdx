## Espacements, formes et contrôles

| Token                                  | Usage                                                                                                                               |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `--space-1` à `--space-12`             | marges, gouttières, espacements internes (4 à 48 px) ; `--space-2` (8 px) entre éléments liés, `--space-4` (16 px) entre blocs      |
| `--radius-md`                          | coins des boutons, champs et cartes ; `--radius-pill` pour les filtres et onglets                                                   |
| `--control-md`                         | hauteur par défaut d'un contrôle (44 px, cible tactile minimale) ; `--control-lg` et `--control-xl` pour les actions mises en avant |
| `--focus-ring`                         | anneau de focus, posé par `base.css` sur `:focus-visible`                                                                           |
| `--z-header` à `--z-toast`             | empilement : header, voile, modale, toast                                                                                           |
| `--duration-fast`, `--duration-normal` | transitions, neutralisées si l'utilisateur réduit les animations                                                                    |

Points de rupture (min-width, mobile d'abord) : 480, 768, 1024 et 1280 px.
