# Legendary Shots — brief pack for UX Pilot

Files (read in this order):
1. `01-pitch.md` — what the product is, for whom, principles.
2. `02-epics-and-user-stories.md` — 10 epics, user stories with the screens they touch (MVP / Later).
3. `03-screen-inventory.md` — explicit list of screens with routes and states, by priority.
4. `04-design-brief.md` — visual direction, colour and type tokens, components, rules and mistakes to avoid.
5. `legendary-shots-brief.pdf` — the same four documents in one PDF, for tools that prefer PDF.

## Suggested prompts
1. "Read all project documents. Plan the Priority 1 screens of 03-screen-inventory.md, mobile (390 px) first. Follow 04-design-brief.md strictly. Start with the plan."
2. "Design screens 1 to 5 (Home, Version page, Capture page, Full-screen viewer, Upload) in mobile and desktop, with the states listed."
3. "Design the empty and fallback states of E8 (launch with almost no content)."
4. "Run a UX review of the Upload flow against stories 2.1 to 2.3."

Notes: no Blizzard assets (all WoW-like elements redrawn in-house); dark theme only; quality colours reserved for captures; use real-looking sample content (zone names like Elwynn Forest, Nagrand, Stormwind City; usernames like Lunelame, Kaelys).
